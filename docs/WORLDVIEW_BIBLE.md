## 1. 创世神话

在时间开始之前，宇宙是一片混沌的「无光之海」。直到第一颗灵魂种子（Aibi Seed）从星海深处坠落，碎裂成无数光片——每一片光都化作了艾比大陆的一块土地、一条河流、一阵风。

灵魂种子的核心化作了大陆中心的艾比小镇，它是所有世界的交汇点，也是旅人出发的地方。种子的碎片散落四方，形成了各大区域的地脉能量——火之脉、风之脉、光之脉、雷之脉、暗之脉……不同地脉滋养出不同的生灵。

**区域描述**（数据库 `world_regions.description_zh/en`，/world 页与探索页区域志弹窗展示）：

- **艾比小镇**：万界交汇的十字路口，来自各地的旅人在此相遇。小镇中央有一棵巨大的「灵魂树」，它的根须连接着大陆每一寸土地。
- **云端群岛**：漂浮在云海之上的破碎岛屿，古代文明遗留的天空遗迹。这里的灵宠天生能感知风的语言。
- **熔岩裂谷**：大地裂缝中涌出的熔岩滋养了火系灵宠。裂谷深处沉睡着古代火龙「焰心」的化石。
- **星雾森林**：终年被星雾笼罩的千年古林，树木上挂着发光的果实。传说森林之心能映照出你内心最渴望的东西。
- **机械废都**：上古文明留下的钢铁之城，如今被雷暴笼罩。废弃的机械中偶尔会「觉醒」出带有灵魂的构造体。
- **蔚蓝海岸**：大陆边缘的广阔海域，海底沉没着古代亚特兰蒂斯遗迹。海獭是这里最机灵的居民，蓝鲸则是海域的守护者。
- **霜语荒原**：终年积雪的北方荒原，极光常年悬挂天际。荒原深处的冰洞里封存着世界最初的记忆。
- **沙漏沙漠**：被时间遗忘的金色沙漠，沙粒中藏着古代文明的碎片。沙漠之眼是一座永不干涸的绿洲。

## 3. 动物观：三种生命形态

| 形态 | 副标题 | 定义 | 代表 |
| --- | --- | --- | --- |
| 凡兽（Mortal Beast） | 普通动物 | 没有地脉能量的普通生物，生活在小镇和各个区域边缘。温顺、平凡，是旅人最初的伙伴。 | 刺猬、陆龟、企鹅、波斯猫 |
| 灵宠（Soul Pet） | 灵魂共鸣兽 | 吸收了地脉能量「灵魂碎片」而觉醒的凡兽，获得特殊能力和智慧。每种灵宠对应一种元素和性格。 | 炎鳞龙(火)、光翼蝶(光)、风灵(风)、钢甲兽(雷) |
| 古灵（Ancient Spirit） | 传说守护兽 | 大陆各区域的远古守护者，传说级别的存在。它们不是被「唤醒」的，而是世界本身意志的化身。 | 焰心(火龙)、云脊(风龙)、星瞳(猫神) |

**系统映射**：凡兽 = 图鉴 catalog 现有物种（pet_dictionary）；灵宠 = AIBI 目录 12 种（aibi_species，src/lib/aibi-catalog.ts）；古灵 = 沉睡传说（`WORLD_ANCIENTS`，不可领养，图鉴「古灵」筛选展示沉睡卡）。

## 5. 核心概念 Glossary

| 概念 | 释义 |
| --- | --- |
| 灵魂种子 | 创世碎片，赋予凡兽觉醒为灵宠的潜能。每次「唤醒」都是种子与旅人灵魂共鸣的结果。 |
| 灵魂卡 | 灵宠灵魂的「镜像」——当灵宠与你共鸣时，它的灵魂会在卡片上留下印记。卡面会随灵宠成长而变化。 |
| 地脉能量 | 大陆各处流动的能量源，不同区域有不同属性。灵宠的力量来源于此。 |
| 羁绊结晶 | 两只灵宠深度共鸣后，灵魂碎片融合凝结成的晶体——是「羁绊」的物质化证明。 |
| 明信片 | 探索各地时自然形成的「风景灵魂碎片」，记录了你到过的每一个地方。 |
| 灵魂树 | 位于艾比小镇中心的神秘大树，连接大陆所有地脉。它是所有灵宠的「故乡」。 |
